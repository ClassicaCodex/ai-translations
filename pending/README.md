## `menota_anonymous_untitled-section-1.json`

25 lines of Gregory's Homily 34, from the Old Icelandic Homilies on the Gospels in AM 677 4to, folios 18r.5–18v.1: the lost coin of Luke 15, the nine orders of angels, and Michael, Gabriel and Raphael.

- **Where the file came from.** It was translated from a library whose plan for AM 677 4to was merged into a single work, "Untitled section 1". There every line is cited by folio and line, and its other five lines (Gregory's Dialogues II.10, folio 40v) were in the same work.
- **What the default plan does instead.** It divides the manuscript into 174 works and gives seven homilies the same identifier, `gregorius`. Each one imported replaces the one before, so the edition `urn:menota:anonymous:gregorius:am-677-4to` holds Homily 33 only. Homily 34's text is not in the library under any identifier.
- **The other five lines** are in `translations/menota_anonymous_untitled-section-105.json`, filed under that division's references in the default plan (`DiII.10.20`–`DiII.10.24`).
- **To return these lines,** wait until Classica Codex imports each homily under an identifier of its own, then file them under that edition. The references here are the manuscript's own folio and line.
